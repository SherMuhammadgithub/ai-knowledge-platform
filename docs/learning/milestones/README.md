## What every milestone folder contains

- `README.md`: the goal, the plan as a checklist, the decisions with their costs, what you should be able to explain at the end, and links to everything else.
- `concepts.md` (from Milestone 5 on): the concepts taught before coding, so you know what is about to happen.
- Topic notes for that milestone (for example `02-embeddings.md`). Older topic notes from Milestones 1 to 4 stay in `docs/learning/` because several milestones add to them, and each milestone README links to them.

Quiz questions and your answers stay in one place, `docs/learning/QUIZ.md`, so nothing is duplicated. Each README links to its section.

## How we work (so you stay in control)

1. Before coding a milestone, I teach its concepts and write its plan here. You read it, and you can change any decision.
2. The plan has checkpoints. I stop at each one, show the result, and wait.
3. The checklist in the milestone README is ticked as work is done, so the folder always shows what is finished and what is left.
4. At the end I update `docs/PROGRESS.md`, this folder, the topic notes and the quiz.
